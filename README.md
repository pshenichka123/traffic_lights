# Симулятор дорожного движения

Приложение на C++17 для Windows. Позволяет нарисовать двусторонние дороги
с несколькими полосами, задать разрешённую скорость, поставить генератор
трафика на отдельную полосу и наблюдать движение машин.
Дороги можно соединять концами; машины продолжают движение по соединённым участкам.
Управляемые перекрёстки и светофоры пока не реализованы.

## Сборка

Нужны CMake 3.16+ и компилятор C++17 (MinGW-w64 или MSVC):

```powershell
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

Запустите `build/traffic_simulator.exe` (для многоконфигурационного генератора —
`build/Debug/traffic_simulator.exe`).

## Управление

1. Укажите число полос в каждую сторону (от 0 до 4; хотя бы одна полоса
   должна существовать) и ограничение скорости
   (10–180 км/ч), выберите **Дорога** и протяните мышь по холсту.
   На дороге появятся полосы в обоих направлениях; стрелки показывают движение.
   Если конец новой дороги подвести к концу существующей ближе чем на 18 пикселей,
   они соединятся. В режиме **Выбрать** можно перетащить дорогу целиком или её
   синий конец; другой конец при этом останется на месте. Редактирование
   геометрии сбрасывает машины и виртуальное время.
2. Выберите **Точка спавна** и нажмите на зелёный вход нужной полосы.
   Каждый вход настраивается отдельно.
3. Выберите точку и введите частоту в машинах в секунду (от 0 до 10),
   а также диапазон начальных скоростей в км/ч, затем нажмите **Применить**.
   Скорости должны лежать между 0 и меньшим из двух пределов: ограничением
   дороги и максимальной скоростью автомобиля.
4. Нажмите **Старт**. Доступны пауза, одиночный шаг 0,05 с и сброс времени.
5. Через **Выбрать** можно отметить дорогу или точку спавна и удалить её.
   Зелёные точки показывают доступные входы полос, красные — выходы.
   На соединённом конце они скрываются, а генератор временно не создаёт машины.

Длина дороги вычисляется из нарисованного отрезка: 5 пикселей = 1 метр.
Полосы имеют отдельные ID и хранятся в хеш-таблице. Дорога хранит ID своих
полос, а машина — ID полосы, по которой движется.

Начальная скорость каждой машины равномерно выбирается из диапазона точки
входа. Машина ускоряется на 2 м/с² до собственной максимальной скорости
13,9 м/с или ограничения дороги и имеет длину 4,5 м. Если она догоняет
машину впереди в своей полосе, модель рассчитывает торможение относительно
скорости передней машины с базовым замедлением 3 м/с². Между машинами
сохраняется минимум 1 м.
Новые машины ждут, если у входа своей полосы нет места. Потоки разных полос
и встречных направлений независимы.
На соединённом конце машина переезжает на следующую дорогу; при занятом входе
ждёт свободного места. Дойдя до свободного конца, она покидает симуляцию. Счётчики показывают
виртуальное время, количество активных, созданных и выехавших машин.
