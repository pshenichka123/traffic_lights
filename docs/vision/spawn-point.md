# SpawnPoint — точка входа

Точка входа привязана к дороге и выбранной полосе одного из направлений. Она задаёт число автомобилей в секунду и диапазон начальных скоростей. Для каждого нового автомобиля скорость выбирается из диапазона равномерно.

На каждом тике точка накапливает число машин по интенсивности и длительности `dt`, затем добавляет их на дорогу при наличии места. Если у входа нельзя сохранить минимальный зазор, создание откладывается. Разные точки входа позволяют отдельно настраивать поток каждой полосы и каждого направления.

Начальная скорость не превышает ограничения дороги и максимальной скорости автомобиля.

На соединённом конце дороги точка входа скрыта и временно не создаёт автомобили. После разъединения дорог её настройки продолжают действовать.
