# Intersection — перекрёсток

Перекрёсток связывает пересекающиеся дороги. Исходный замысел предусматривает дороги по четырём направлениям и [контроллер светофора](traffic-light-controller.md). Пользователь должен иметь возможность размещать перекрёстки при построении схемы.

Для проезда через них потребуется определить соединение полос, допустимые направления движения и переход машин с одной дороги на другую. Правила поворотов и приоритета пока не заданы. Класса перекрёстка в текущем коде нет.
