# Object — общий объект симуляции

Все участвующие в цикле объекты наследуют общий класс и имеют метод `act(simulation, dt)`, вызываемый в каждом тике. `dt` задаёт длительность шага в секундах. Этот интерфейс используют автомобили, точки входа, дороги и полосы.

Код: [`object.h`](../../src/Objects/Object/object.h), [`object.cpp`](../../src/Objects/Object/object.cpp).
