# Архитектура симулятора

Проект на C++ моделирует дорожное движение автомобилей. Пользователь рисует конфигурацию дорог и перекрёстков как схему связей, задаёт интенсивность потока через точки входа, запускает симуляцию и наблюдает движение машин.

## Состав системы

- [Simulation](simulation.md) хранит дороги, полосы, точки входа и автомобили, выполняет тики и ведёт виртуальное время.
- [Object](object.md) задаёт общий метод `act()` для объектов симуляции.
- [Road](road.md) описывает двусторонний участок и содержит ID полос каждого направления.
- [Lane](lane.md) описывает одну полосу и связывает автомобиль с дорогой.
- [SpawnPoint](spawn-point.md) подаёт автомобили на выбранную полосу.
- [Car](car.md) хранит параметры и состояние автомобиля, рассчитывает его движение.
- [Intersection](intersection.md) и [TrafficLightController](traffic-light-controller.md) описывают будущую работу с пересечениями дорог.

Связи по идентификаторам: автомобиль → полоса → дорога. Все полосы хранятся в хеш-таблице симуляции, а дорога хранит списки ID своих полос. Точка входа привязана к дороге и конкретной полосе.

В текущей реализации можно рисовать и соединять двусторонние дороги концами, редактировать их геометрию, настраивать поток каждой полосы и наблюдать движение автомобилей через соединения. Модель перекрёстков с правилами поворотов, приоритетом и светофорами пока не реализована.
