# Lane — полоса движения

У полосы есть уникальный ID и ID дороги, которой она принадлежит. Полосы хранятся в хеш-таблице симуляции для поиска по ID. Полоса также задаёт направление и индекс среди полос этого направления.

Автомобиль хранит ID своей полосы. Дорога хранит списки ID полос отдельно для двух направлений. Интенсивность потока настраивается через точку входа на выбранной полосе.
